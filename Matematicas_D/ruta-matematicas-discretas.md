## Módulo 1: Lógica  [x]

**Objetivo:** Comprender la lógica proposicional, los conectores lógicos, las tablas de verdad y su aplicación a circuitos lógicos.

- [x] Proposiciones y proposiciones simples/compuestas; valor de verdad (V/F)
- [x] Conectores lógicos: conjunción (y), disyunción débil (o), disyunción fuerte (o…o), implicación (si…entonces), equivalencia (si y solo si), negación (no es verdad)
- [x] Construcción de tablas de verdad para proposiciones compuestas
- [x] Tautología, contradicción y contingencia
- [x] Circuitos lógicos: interruptor, generador, bombillo; circuitos en serie y en paralelo
- [x] Representación de conectores en circuitos eléctricos (1 = V, 0 = F)
- [x] Reto/evaluación: construir la tabla de verdad de una proposición compuesta y clasificarla (tautología/contradicción/contingencia), y representarla como circuito lógico

---

## Módulo 2: Teoría de Conjuntos  [x]

**Objetivo:** Dominar la definición de conjuntos, sus operaciones básicas, la representación gráfica y las leyes de De Morgan.

- [x] Concepto de conjunto, elementos y relación de pertenencia
- [x] Determinación de un conjunto por extensión y por comprensión; cardinalidad; conjuntos finitos e infinitos
- [x] Conjuntos especiales: nulo (vacío), unitario y universal
- [x] Subconjuntos
- [x] Operaciones entre conjuntos: unión, intersección, resta (diferencia) y complemento
- [x] Representación gráfica de conjuntos y operaciones (diagramas de Venn)
- [x] Leyes de De Morgan (unión e intersección)
- [x] Reto/evaluación: resolver ejercicios de operaciones combinadas con conjuntos usando diagramas de Venn

---

## Módulo 3: Teoría de Grafos  [x]

**Objetivo:** Comprender qué es un grafo, sus tipos, el grado de los vértices, los caminos/ciclos y las representaciones matriciales.

- [x] Definición de grafo: vértices (V) y aristas (E); modelos matemáticos de relaciones
- [x] Tipos de grafos: simple, ponderado, multigrafo, pseudografo, dirigido y multigrafo dirigido
- [x] Grado de un vértice
- [x] Caminos, cadenas, cadenas cerradas, ciclos; grafos conexos y no conexos
- [x] Caminos y ciclos eulerianos (condición de grados par/impar; algoritmo de Fleury)
- [x] Caminos y ciclos hamiltonianos
- [x] Matriz de adyacencia (grado de cada vértice)
- [x] Matriz de incidencia
- [x] Reto/evaluación: construir la matriz de adyacencia e incidencia de un grafo dado y determinar si admite camino/ciclo euleriano o hamiltoniano

---

## Módulo 4: Árboles  [x]

**Objetivo:** Reconocer los tipos de árboles, su estructura jerárquica, recorridos y aplicaciones (expresiones aritméticas y árbol de expansión mínima).

- [x] Introducción a los árboles y sus aplicaciones (jerarquías)
- [x] Tipos de árboles: libres, con raíz, de expansión, binarios
- [x] Subárboles, vértices terminales e internos, padre, hijos, ancestro
- [x] Nivel y altura de un árbol
- [x] Árboles binarios: completo, lleno, degenerado; estructura recursiva
- [x] Recorridos: preorden, inorden, postorden
- [x] Árboles binarios para expresiones aritméticas (prefijo, infijo, postfijo; prioridad de operadores)
- [x] Árbol de expansión mínima
- [x] Reto/evaluación: determinar nivel y altura de un árbol dado, realizar sus recorridos y transformar una expresión aritmética en árbol binario

---

## Módulo 5: Algoritmos  [x]

**Objetivo:** Aplicar los algoritmos fundamentales de grafos sobre árboles y redes.

- [x] Algoritmo de Prim (árbol de expansión mínima)
- [x] Algoritmo de Kruskal (árbol de expansión mínima)
- [x] Algoritmo de Dijkstra (ruta/coste mínimo)
- [x] Algoritmo de Fleury (ciclos eulerianos)
- [x] Algoritmo de flujo máximo
- [x] Reto/evaluación: aplicar Prim, Dijkstra, Kruskal y Fleury sobre grafos de práctica y comparar resultados
